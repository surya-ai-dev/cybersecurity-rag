================================================================================
CYBERSECURITY RAG SYSTEM — ARCHITECTURE & PROJECT STRUCTURE
================================================================================

1. HIGH-LEVEL FLOW ARCHITECTURE
--------------------------------------------------------------------------------

User Query
    │
    ▼
RAGEngine (app/pipeline/engine.py)
    │
    ├── 1. Conversation History ──> ConversationMemory (app/conversation/conversation_memory.py)
    │
    ├── 2. Query Rewriting ───────> QueryRewriter (app/conversation/query_rewriter.py)
    │                                  │ (resolves conversational context/pronouns)
    │                                  ▼
    ├── 3. Candidate Retrieval ───> HybridRetriever (app/retrieval/hybrid.py)
    │                                  ├── DenseRetriever (app/retrieval/dense.py)
    │                                  │     (BGE-small-en-v1.5 + local Qdrant, Top-20)
    │                                  ├── BM25Retriever (app/retrieval/bm25.py)
    │                                  │     (Rank-BM25 over 7,703 chunks, Top-20)
    │                                  └── RRFFusion (app/retrieval/rrf.py)
    │                                        (Reciprocal Rank Fusion, K=60, Top-20)
    │
    ├── 4. Reranking ─────────────> CrossEncoderReranker (app/retrieval/reranker.py)
    │                                  (ms-marco-MiniLM-L-6-v2, Top-5 selected)
    │
    ├── 5. Context Building ──────> ContextBuilder (app/generation/build_context.py)
    │                                  (Pure formatting of Top-5 chunks into SOURCE blocks)
    │
    ├── 6. LLM Generation ────────> BaseLLMProvider / GroqProvider (app/generation/providers/groq_provider.py)
    │                                  (Groq Cloud SDK, openai/gpt-oss-20b, temperature=0.0)
    │
    ├── 7. Turn Recording ────────> ConversationMemory.add_message()
    │
    └── 8. Result Delivery ───────> RAGResponse (app/core/models.py)
                                       (Question, Standalone Question, Answer, Sources)


2. PROJECT DIRECTORY STRUCTURE
--------------------------------------------------------------------------------

cybersecurity-rag/
│
├── main.py                             # Interactive CLI entry point using RAGEngine
│
├── app/                                # Core application package
│   ├── __init__.py
│   │
│   ├── core/                           # Foundation layer (zero external app dependencies)
│   │   ├── __init__.py
│   │   ├── config.py                   # Centralized configuration (paths, models, hyperparameters)
│   │   ├── interfaces.py               # Abstract protocols (BaseRetriever, BaseReranker, BaseLLMProvider, BaseConversationMemory)
│   │   └── models.py                   # Domain models (RetrievedChunk, ChunkMetadata, Message, RAGResponse)
│   │
│   ├── retrieval/                      # Search and ranking layer
│   │   ├── __init__.py
│   │   ├── dense.py                    # DenseRetriever (BGE embeddings + Qdrant vector database)
│   │   ├── bm25.py                     # BM25Retriever (Rank-BM25 keyword search)
│   │   ├── rrf.py                      # RRFFusion (Reciprocal Rank Fusion algorithm)
│   │   ├── hybrid.py                   # HybridRetriever (Orchestrates Dense + BM25 + RRF)
│   │   ├── reranker.py                 # CrossEncoderReranker (Cross-encoder reranking)
│   │   ├── retriever.py                # Backward-compatibility wrapper for legacy imports
│   │   ├── bm25_retriever.py           # Backward-compatibility wrapper for legacy imports
│   │   ├── rrf_fusion.py               # Backward-compatibility wrapper for legacy imports
│   │   └── hybrid_reranker.py          # Backward-compatibility wrapper for legacy imports
│   │
│   ├── generation/                     # Context building and LLM generation layer
│   │   ├── __init__.py
│   │   ├── build_context.py            # Pure context builder (Formats chunks into prompt context)
│   │   ├── llm.py                      # Backward-compatibility generation wrapper delegating to GroqProvider
│   │   └── providers/
│   │       ├── __init__.py

│   │
│   ├── conversation/                   # Conversational state and rewriting layer
│   │   ├── __init__.py
│   │   ├── conversation_memory.py      # ConversationMemory implementing BaseConversationMemory
│   │   └── query_rewriter.py           # Query rewriter resolving multi-turn context
│   │
│   ├── pipeline/                       # End-to-end orchestration layer
│   │   ├── __init__.py
│   │   ├── engine.py                   # RAGEngine (Main application orchestrator)
│   │   └── rag_pipeline.py             # Backward-compatibility wrapper delegating to RAGEngine
│   │
│   └── ingestion/                      # Offline ingestion pipeline
